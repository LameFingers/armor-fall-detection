# Edge Impulse ML Screenshots

This folder contains screenshots of the Edge Impulse project taken during
ARMOR model development.

See [`evidence/README.md`](../README.md) for the full list of recommended
screenshots and the file naming convention.

## How to add screenshots

1. Take a screenshot in your browser while on the relevant Edge Impulse page.
2. Save the file with a descriptive name following the convention:
   ```
   YYYY-MM-DD_description.png
   ```
   Example:
   ```
   2025-07-20_confusion-matrix.png
   2025-07-20_data-explorer-class-separation.png
   2025-07-20_impulse-design.png
   2025-07-20_training-accuracy.png
   ```
3. Place the file in this folder (`evidence/ml-screenshots/`).
4. Commit and push normally — GitHub will display `.png` and `.jpg` files
   inline when you browse this folder.
