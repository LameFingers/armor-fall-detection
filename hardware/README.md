# Armor Hardware

This folder will contain wiring diagrams, component notes, the bill of
materials, enclosure files, and prototype photographs.

## Planned prototype components

- ESP32-S3 development board
- BMI270 inertial measurement unit
- LoRa transmitter module or LoRa-enabled ESP32-S3 board
- Second LoRa device for gateway or receiver testing
- Buzzer
- LED and current-limiting resistor
- Optional push button for alert cancellation
- Rechargeable LiPo battery
- Charging and power-management circuit
- Breadboard and jumper wires for the first prototype
- Protoboard or perfboard for a more durable prototype
- 3D-printed enclosure

## Development sequence

1. Breadboard prototype and sensor verification
2. Local alert and cancel-button testing
3. LoRa message transmission and receiver testing
4. Battery-powered prototype
5. Transfer to protoboard or perfboard
6. 3D-printed enclosure integration

## Current status

Hardware has not been assembled yet. The bill of materials and wiring diagrams
will be added after final component selection.
